## 가. 저희가 임시로 정한 것 — 확인 부탁드립니다

### 1. 동반자 영문 이름을 예약할 때 모두 받아도 될까요?

| 항목 | 내용 |
|---|---|
| 질문 | 예약할 때 대표자뿐 아니라 동반자 전원의 여권 영문 성·이름을 모두 입력받아도 될까요? |
| 필요한 이유 | 나중에 입력받으면, 출발 전까지 이름이 들어오지 않은 예약을 따로 확인하고 연락하는 과정이 필요해 운영이 복잡해집니다. |
| 현재 임시 처리 | 예약할 때 동반자 전원의 성·이름을 필수로 받습니다. 예약 후에는 출발 7일 전까지 예약 상세 화면에서 오타만 고칠 수 있습니다. |
| 답 형식 예시 | 예 / 아니오 (아니오라면 언제까지 받으면 되는지) |

### 2. 영문 이름에 하이픈(-)·아포스트로피(')를 허용해도 될까요?

| 항목 | 내용 |
|---|---|
| 질문 | 여권 이름에 하이픈이나 아포스트로피가 들어간 경우(예: KIM MIN-JI, O'BRIEN SEAN) 그대로 입력받아도 될까요? |
| 필요한 이유 | 여권과 다른 표기로 입력되면 골프장·호텔 명단과 맞지 않을 수 있습니다. |
| 현재 임시 처리 | 영문 대문자와 하이픈·아포스트로피를 허용합니다. 성과 이름은 모두 필수입니다. |
| 답 형식 예시 | 예 / 아니오 (아니오라면 허용할 문자) |

### 3. 희망 승차 시간을 고를 수 있는 범위

| 항목 | 내용 |
|---|---|
| 질문 | "손님이 희망 승하차 장소를 시간과 함께 입력하도록" 하라는 답변(10/19)에 따라 희망 승차 시간을 받고 있습니다. 고를 수 있는 범위를 아래처럼 정해도 될까요? |
| 필요한 이유 | 범위가 너무 넓으면 일정상 불가능한 시간이 들어오고, 너무 좁으면 합승 버스가 여러 그룹을 차례로 태울 시간이 부족합니다. |
| 현재 임시 처리 | 첫날 첫 티오프 **2시간 30분 전부터**, "티오프 − 승차 장소에서 골프장까지 이동 시간 − 30분"**까지** 30분 단위로 고릅니다. (예: 12:30 티오프, 이동 40분 → 10:00 ~ 11:00) 화면에는 "합승 버스가 여러 그룹을 차례로 태우므로, 일찍 타면 골프장에서 티오프까지 기다릴 수 있다"는 안내를 넣었습니다. 실제 승차 시간은 출발 확정 후 메일로 안내합니다. |
| 답 형식 예시 | 이대로 좋음 / 시작·끝 시각을 바꿈 (바꾼다면 기준) |

### 4. 희망 하차 시간은 선택으로 해도 될까요? (하차 장소는 필수)

| 항목 | 내용 |
|---|---|
| 질문 | 답변에서 하차 희망을 시간과 함께 받으라고 하셨는데, 실제 하차 시간은 도로 상황·합승 인원에 따라 바뀌어 약속하기 어려워 선택으로 했습니다. 이렇게 해도 될까요? |
| 필요한 이유 | 하차 시간을 필수로 받으면 손님이 그 시간에 내릴 수 있다고 오해할 수 있습니다. |
| 현재 임시 처리 | 하차 장소는 필수, 하차 희망 시간은 선택입니다. 화면에 "도로 상황과 합승 인원에 따라 실제 하차 시간은 달라질 수 있다"는 안내를 넣었습니다. |
| 답 형식 예시 | 선택으로 좋음 / 필수로 바꿈 |

### 5. 정원 20명 = 최소 출발 인원 20명

| 항목 | 내용 |
|---|---|
| 질문 | 출발편(버스 1대) 정원과 최소 출발 인원이 모두 20명이라, 20석이 모두 차야만 출발하고 한 자리라도 비면 운행이 취소됩니다. 의도하신 운영 방식이 맞나요? |
| 필요한 이유 | 이대로라면 운행 취소가 자주 생길 수 있습니다. 출발 여부 판단과 손님 안내 문구가 이 값에 따라 달라집니다. |
| 현재 임시 처리 | 정원 20명, 최소 출발 20명으로 개발했습니다. 출발 7일 전에 20명이 모이지 않으면 운행이 취소되고 전액 환불됩니다. |
| 답 형식 예시 | 이대로 맞음 / 최소 출발 인원을 ○명으로 / 정원을 ○명으로 |

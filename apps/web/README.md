# 홋카이도 버스 골프 패키지 예약 프로토타입

TRAVENDER 본 사이트의 '골프' 카테고리로 들어가는 모바일 웹 예약 서비스 프로토타입입니다.
노션 페이지 「홋카이도 골프 예약 연동 시스템」과 첨부·링크 자료를 모두 반영했고,
화면 구조와 흐름은 **최하단 화면 설계서 「골프 투어 화면설계서 v1.0 초안」**을 기준으로 했습니다.

## 다른 사람과 공유하기 (시작.bat)

`시작.bat` 을 더블클릭하면 아래가 자동으로 진행됩니다.

1. 처음이면 필요한 파일 설치 (1~2분)
2. 최신 내용으로 빌드
3. 내 PC에서 미리보기 서버 실행
4. Cloudflare 임시 터널로 공개 링크(`https://….trycloudflare.com/#/golf`) 생성
5. 브라우저로 링크 열기 + 클립보드 복사 + `공유링크.txt` 저장

메신저에 붙여 넣어 보내기만 하면 됩니다. 받는 사람은 설치 없이 휴대폰·PC 브라우저로 엽니다.

- 검은 창이 열려 있는 동안에만 링크가 살아 있어요. 창을 닫거나 PC가 꺼지면 링크도 꺼집니다.
- 실행할 때마다 주소가 새로 바뀝니다. 다시 실행했다면 새 링크를 보내 주세요.
- 필요한 것: Node.js 18 이상, cloudflared (이 PC에는 이미 설치되어 있음). Cloudflare 계정은 필요 없습니다.
- 예약 내역은 보는 사람 각자의 브라우저에만 저장되어 서로 섞이지 않습니다.

## 내 PC에서만 실행 (개발용)

`내PC에서만_실행.bat` 더블클릭, 또는:

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 같은 와이파이의 휴대폰에서는 터미널에 표시되는 `Network:` 주소로 열 수 있습니다.

배포용 빌드는 `npm run build` → `npm run preview` 로 확인합니다.

## 테스트 시나리오

1. **기본 예약**: 홈 → 출발일(필수) + 인원 12명 → 패키지 검색 → 패키지 → 출발일 → 호텔 옵션 → 승차·하차 지정 → 확인 → 로그인(데모 계정) → 정보 입력 → 결제 → 완료 → 예약 상세
2. **입력 오류**: 출발일 없이 '패키지 보기'(비활성) / 인원 31명 / 영문 이름에 한글 / 약관 미동의
3. **시내 밖 승하차**: S-06에서 '오타루역'을 고르거나 지도에서 초록 원 밖을 누르면 M-006 안내 후 지정되지 않음
4. **잔여석 부족**: 인원을 크게 하면 잔여석이 적은 출발일이 '잔여석 부족'으로 비활성
5. **출발 확정**: 같은 출발편 합계가 20명 이상이 되어도 예약 직후는 '인원 충족'. '출발 확정'은 판정일(출발 3일 전) 판정 후 (L-04)
6. **변경 후 복귀**: S-08의 '변경' → 고친 뒤 '변경 완료' → S-08로 돌아옴
7. **결제 실패·시간 초과**: S-10 데모 칸에서 '실패' 선택 / 10분 확보 시간이 지나면 M-014 후 S-03
8. **언어**: 헤더의 KO / JA (선택은 다음 방문에도 유지, 첫 방문은 브라우저 언어)
9. **PC**: PC 전용 배치 없음. 모바일 화면이 PC에서도 가운데에 그대로 표시 (N-001)
10. **홀수 인원**: 3명 → 호텔 옵션에서 객실 '2인실 1실 · 1인실 1실' 자동, 1인실 추가 요금이 S-08 요금에 표시
11. **중복 예약**: 로그인 후 이미 예약한 출발편(예약 목록 첫 건)을 다시 예약하면 S-08에서 확인 창 (M-152)

## 설계 도구 (오른쪽 아래 '설계' 버튼, 실서비스 제외)

- **설계서 번호 표시**: 화면마다 설계서의 주황 번호, 화면 ID·관련 요건, 노란 확인 필요(Q) 태그를 겹쳐 보여 줌
- **MVP 단계 미리보기**: 1단계 / 2단계(추천 패키지, 비교, 포함 사항 내역, 출발 확정 현황) / 3단계(AI 추천 입구)
- **상태 데모**: 다음 불러오기 통신 오류, 로그인 상태 전환, 다음 결제 결과, 테마(시스템·라이트·다크), 예약 데이터 비우기(빈 상태 확인)·다시 넣기
- **화면 바로가기**: S-01~S-14로 바로 이동 (예약 단계는 예시 값으로 채워서 엶)

## Google 지도 (Maps JavaScript · Places · Routes)

- 지도는 모두 Google 지도입니다: S-03 위치 지도, S-05 호텔 위치, S-06 승하차 지정, S-13 여행 지도
- **S-06 건물·가게 선택**: 지도에서 건물·가게 아이콘을 누르면 이름·주소·시내 여부가 미리보기로 뜨고, '이곳을 승차/하차 장소로'로 지정합니다. 빈 곳을 눌러 좌표로 고를 수도 있습니다. 검색창은 Google 장소 자동완성입니다.
- **예상 이동 시간**: Google 경로(승용차, 교통 상황 미반영) 기준
  - S-06 미리보기와 지정 후: 승차 장소 → 첫 골프장, 마지막 장소 → 하차 장소
  - S-05: 호텔 → 각 골프장
  - S-03·S-08·S-13 일정표: 항목 사이 구간마다
  - 예상 승차 시간도 이 경로 시간으로 계산합니다.
- 키: 프로젝트 폴더의 `.env.local` 에 `VITE_GOOGLE_MAPS_API_KEY=…`. 빌드할 때 화면 코드에 들어가므로 Google Cloud 콘솔에서 웹사이트 제한(`*.trycloudflare.com/*`, `http://localhost:*/*`)과 API 제한(Maps JavaScript API, Places API (New), Routes API)을 꼭 걸어 두세요.
- 키가 없거나 막히면 지도 자리에 안내 문구가 나오고, 이동 시간은 직선거리로 계산한 '대략' 값으로 바뀝니다.
- 비용 절약: 골프장·호텔 좌표는 데이터에 고정(검색 없음), 경로 결과는 브라우저에 저장해 같은 구간은 다시 요청하지 않습니다. 마커용 지도 ID는 Google 데모 ID(`DEMO_MAP_ID`)이며 실서비스에서는 콘솔에서 만든 Map ID로 바꿉니다.
- `.env.local` 과 `credentials` 폴더는 개발 서버 주소로 열리지 않도록 막아 두었습니다.

## 프로토타입의 한계

- 패키지 구성·가격(엔화)·출발 요일·좌석 수·사진은 예시입니다. (Q-02, Q-08, Q-14)
- 이동 시간은 승용차 기준이라 합승 버스의 경유·정차 시간은 들어가지 않습니다.
- '시내' 범위는 삿포로·기타히로시마·치토세(공항 포함) 원으로 가정했습니다. 정확한 기준은 확인이 필요합니다.
- 로그인·결제·이메일 발송은 데모입니다. 예약 데이터는 이 브라우저(localStorage)에만 저장됩니다.
- 사진: Unsplash 이미지 (인터넷 연결 필요)
